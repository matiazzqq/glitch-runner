## 🔥 О игре

**GLITCH RUNNER** — первая игра вселенной **CHAOS REALM**. Это хардкорный раннер, где главная механика — непредсказуемость окружения. Платформы имеют свойство "глитчиться": становиться видимыми и невидимыми случайно. Игроку нужно запоминать паттерны и реагировать мгновенно.

### ✨ Особенности

- 📺 **Эффект Глитча**: Платформы исчезают и появляются. Экран трясется при ошибках.
- 🎨 **Неоновая эстетика**: Черный фон, яркие циановые и магентовые цвета.
- 🚀 **Высокая скорость**: Игра ускоряется каждые несколько секунд.
- 💎 **Сбор фрагментов**: Золотые ромбы дают очки.
- 🔊 **Индустриальный звук**: Синтезированные звуки прыжков и краха системы.
- 📱 **Mobile Ready**: Управление тапом.

## 🕹 Управление

- **Space / Click / Tap**: Прыжок.
- **Двойное нажатие**: Двойной прыжок (воздушный рывок).
